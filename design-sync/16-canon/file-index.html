File index

The rule

Folder numbers match the section numbers in the readme. A ground owns its ENTIRE language in its own folder — its tokens, its element classes, and its cards. Nothing about a ground lives outside its folder, and no ground reaches into another's file.

Global

styles.css — the entry point. Imports the four token files, then each ground's CSS directly.

tokens/radii.css — the shared radius ladder. tokens/ — brand-wide only: fonts.css · colors.css (◆ brand core, inks, hairlines, label colours, semantic twins) · typography.css · motion.css

assets/ — logo/ official marks · photos/ credited field photography · textures/ official linework plus the purpose-drawn Terrain sheets (topo-contours.svg, true iso-lines by marching squares, so contours nest and never cross) · broadcast/ approved board SVGs · fonts/ Tungsten OTFs

The grounds — 01 to 08

01-grounds/ — the six side by side, and the cross-ground laws

02-navy-ground/ — dusk ramp tokens, .navy-ground

03-photo-ground/ — directional scrim tokens, .photo-ground, the scrim law

04-field-glass/ — approved ✅ the instrument material: .fgi crystal, .fgi-well, etched separators, settle motion, all --fgi-*. Also holds .fgi--frost, used by section 06.

05-terrain-paper/ — sheet, tooth, mottle and contour tokens, .terrain, and the frost plate — Terrain's card, a Field Glass variant with no CSS of its own — and the linework primitives (.tp-rule-v dotted, .tp-rule-h solid, survey crosses, scale bar)

06-roadbook-paper/ — Adopted ✅, ships in live scoring: cool white, deliberately plain

07-broadcast-on-air/ — the origin: ✅ --bc-* overlay tokens, rb-* elements, and the RaceLine placement law

The kit and the documentation — 09 to 16

08-components/ — Button, Chip and Card, plus the page patterns — nav bar, text link, fields, icon button, section head, quote, enlist band. Appearance lives in components.css (loaded by styles.css) so plain-HTML cards wear the real thing; the .jsx only maps props to those class names. Plus the shared radius scale, the Tabler icon system, marks and lists, and the native-platform division of responsibility

09-marks-and-assets/ — shield, compass star, wordmark and lockups, official textures

10-color/ — the brand-wide colour section: the palette, the field map of which colour does which job on which ground, the label/hairline floor, the paper twins, and the two accents. Values live in tokens/colors.css; ground-specific colour stays with its ground

11-type/ · 12-voice/ · 13-principles/ · 14-imagery/ · 15-channels/ — the written system, rendered

16-canon/ — sources, build order, content and visual foundations, and this index
